Pure Essence

A minimalist skincare brand website, designed in Figma and hand-coded in HTML & CSS for a UI/UX course project.

Role Designer & Developer
Timeline 2025
Tools Figma, HTML, CSS, Word
Deliverables Responsive Website, Design Spec

Pure Essence is a concept e-commerce site for a minimalist skincare brand, built for a UI/UX course. I designed the visual system in Figma — layout, typography, color, and product card patterns — then hand-coded the site in HTML and CSS, and wrote up the design specification and rationale in a companion Word document.
